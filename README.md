# Lumière — Skincare Rituals

> *"Because good skin starts with honest care."*

A clean, elegant skincare brand landing page built with pure HTML, CSS, and JavaScript — no frameworks, no libraries. Designed for a fictional Lahore-based brand that values honest ingredients and intentional design.

## Features

- **Custom cursor** — Dot + ring cursor with smooth hover expand animation
- **Page transition** — Elegant scaleY reveal overlay on load
- **Scroll animations** — IntersectionObserver-based fade/slide reveal effects
- **Marquee strip** — Auto-scrolling brand values ticker
- **Mobile menu** — Hamburger nav with fullscreen slide-in overlay
- **Ingredient popups** — Per-product modal with detailed ingredient breakdown cards
- **Fully responsive** — Works across mobile, tablet, and desktop

## Design Decisions

The color palette — warm creams, beiges, and mochas — was intentionally chosen to feel like a luxury editorial magazine, not a generic e-commerce template.

Typography pairs **Cormorant Garamond** (elegant serif, used for headings and brand moments) with **Jost** (clean geometric sans, used for body text and UI elements).

All animations are CSS-driven or vanilla JS — zero third-party dependencies, zero bundle size.



## Pages / Sections

- **Hero** — Full-viewport intro with headline, description, and product CTAs
- **Marquee** — Scrolling strip of brand values (Cruelty Free, Dermatologist Tested, etc.)
- **Our Story** — Founder's note with stacked image layout and brand stats
- **Shop** — 3-product grid with ingredient popup modals
- **Footer** — Brand tagline, navigation links, and social links
